# Portfolio

Source for [matthewgcastle1.github.io](https://github.com/matthewgcastle1/portfolio) (or wherever this is hosted) — a personal site for Matthew Castle: software engineer background, work experience, and a set of interactive math/CS simulations.

Static HTML/CSS/JS, no build step or framework.

## Structure

- `index.html` — home page: bio, experience, other projects, tools, education.
- `demos.html` — index of the interactive demos.
- `demos/` — individual simulation pages (double pendulum, Lorenz attractor, Mandelbrot/Julia sets, cellular automata, Fourier transform, neural network, sorting algorithms, matrix transformations, quaternions vs. Euler angles, change of basis, complex analysis, central limit theorem, Newton fractals).
- `css/style.css` — shared styling.
- `Matthew_Castle_Resume.pdf`, `MatthewCastleResume2.pdf` — downloadable resumes linked from the home page.

## Deployment

The site deploys automatically on push to `main`.
